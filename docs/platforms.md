# Platforms

Zoop is designed to eventually target a wide range of platforms.

*Note: These are planned platform targets, not necessarily implemented currently.*

## Planned Platforms

- **Android**: For mobile endpoints (phones, tablets).
- **iOS**: For mobile endpoints (iPhones, iPads).
- **Linux**: For backend agents and generic Linux devices.
- **Desktop**: Windows and macOS support for end-users.
- **OpenWrt**: Integration for consumer and prosumer routers.
- **Routers**: General embedded Linux router environments.
- **Future network-capable hardware**: IoT and edge devices.
