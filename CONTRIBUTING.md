# Contributing to Zoop

Thank you for your interest in contributing to Zoop! 

Currently, the project is in the **architecture and design phase**. We welcome contributions to the documentation, architecture diagrams, and concept reviews.

## How to Contribute

1. Review the existing documentation in the `docs/` folder.
2. Discuss major changes in Issues before opening a Pull Request.
3. Submit a Pull Request with your proposed changes or additions to the design.
